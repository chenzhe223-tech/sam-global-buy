# 好物清单 · 双十一全球购

一个移动端优先的亲友拼单网页：用商品卡片展示选品、分享清单链接、由朋友勾选数量并提交订单；组织者可集中查看订单、调整附加费用/优惠、生成微信账单文本和导出 CSV。

> **注意**：此项目不是山姆会员商店官方产品，也不会自动登录/抓取山姆 App。商品示例、图片和价格只用于界面演示。正式使用时请以你有权访问的商品信息为准，人工录入或通过 CSV 导入名称、图片地址和价格；实际售价、库存、规格和购买资格以山姆 App 下单页面为准。

## 功能

- 响应式选品展示页，适配手机、桌面浏览器。
- 商品名称、品牌、分类、价格、图片、标签和说明。
- 搜索与分类筛选，增减商品数量，生成个人购物清单。
- 一键分享当前清单网址；朋友提交后可记录称呼、商品快照、数量和备注。
- 组织者后台：新增/编辑/隐藏/删除商品，手动录入、上传压缩图片、批量 CSV 导入。
- 订单管理：状态流转、费用和优惠调整、复制账单文本、标记“已发账单/已结清”、CSV 导出。
- 两种运行模式：不配置后端时是**本机演示模式**；接入 Supabase 后，商品与订单才会跨设备同步。
- 不处理真实微信支付，不会自动转账；微信账单由组织者核对后手动发送。

## 最快体验

直接在浏览器打开 `index.html`，或在本地文件夹运行一个静态服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。未配置数据库时，添加的商品和订单只保存在当前浏览器的 localStorage，不能用于多人真实拼单。

## 发布到 GitHub Pages

1. 在 GitHub 创建独立仓库 `sam-global-buy`。
2. 将本项目全部文件放在仓库根目录，包括隐藏的 `.nojekyll` 和 `.github/workflows/deploy-pages.yml`。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 的 **Source** 中选择 **GitHub Actions**。
4. 向 `main` 推送代码后，工作流会自动发布；也可以在 **Actions** 页面手动运行。
5. 发布成功后，网页地址通常为 `https://你的GitHub用户名.github.io/sam-global-buy/`。

只启用 GitHub Pages 仍然只是静态网站；想要多人共享订单，请完成下一节 Supabase 配置。首次公开收单前请完成数据库配置和权限测试，不要把演示模式当作真实订单后台。

## 启用云端共享（Supabase）

### 1. 创建数据库

1. 在 Supabase 创建一个新项目。
2. 打开 **SQL Editor**，把 `database.sql` 全部粘贴进去并执行。
3. 在 **Authentication → Providers / Sign In** 中关闭公开用户注册。
4. 在 **Authentication → Users** 中创建管理员用户（邮箱 + 密码）。
5. 在项目 API 设置页获取 **Project URL** 和 **anon / publishable key**。

### 2. 配置前端

编辑 `config.js`：

```js
window.SAM_LIST_CONFIG = {
  campaignTitle: "双十一全球购清单",
  supabaseUrl: "https://你的项目ID.supabase.co",
  supabaseAnonKey: "你的 anon 或 publishable key",
  currency: "CNY"
};
```

只使用 `anon / publishable key`，**不要**使用 `service_role` 或 secret key。前端 key 不是管理员密码；数据访问安全依赖 SQL 中的 RLS 策略和关闭公开注册。

提交并推送 `config.js` 后，朋友访问同一个页面即可读取商品并提交订单；组织者用 Supabase 管理员账号登录后台。添加/隐藏/更新商品和查看订单需要管理员登录。

### 3. 发布前验证

- 无需登录即可看到展示中的商品。
- 无需登录可以提交购物清单。
- 未登录用户不能读取订单列表。
- 组织者账号能登录后台并管理商品、查看订单。
- 用两台设备分别提交测试订单，确认后台都能看见。
- 删除测试订单前，请先在后台导出 CSV 备份。

## 批量录入商品

后台 → **商品管理** → **下载模板**，或按 `sam-products-template.csv` 的列格式准备文件：

`name,price,image_url,category,brand,tag,product_url,description`

`image_url` 可以填写可直接访问的图片链接；如图片只在 App 内可见，可把你有权保存的商品图保存到设备，再用后台上传。小规模拼单的图片会压缩为 WebP 后存入商品记录。

当前没有自动采集山姆 App 数据。App 内信息可能依赖登录、动态接口或访问限制，因此本项目不绕过登录、验证码或访问控制。后续若获得官方允许的商品接口或授权数据源，可以再增加自动同步适配器。

## 重要边界

- 本工具是亲友需求收集和人工对账工具，不是山姆官方页面。
- 订单中的金额在前端生成，仅用于预估与对账；请对照实际下单记录人工核验。
- 本工具不收集微信支付密码，不处理微信支付 API，也不会自动发送微信消息。
- 公开的静态链接可能被转发；请只向信任的亲友分享。匿名提交接口可能被滥用，如公开范围扩大，应再加验证码/限流机制。

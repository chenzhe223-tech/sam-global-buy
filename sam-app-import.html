从山姆 App 导入真实商品

把你通过正常登录使用山姆 App 时获得的商品列表 JSON，或包含该响应的 HAR 文件，转换成“好物清单”可以直接导入的 CSV。

隐私说明：这个页面在你的浏览器本地处理文件，不会把文件、登录信息或商品数据上传到服务器。请勿把包含 auth-token、Cookie 或个人信息的 HAR 发给他人；导出的 CSV 只包含商品展示字段。

01 · 选择数据文件

支持山姆商品列表接口的 JSON 响应、JSON 文件，或浏览器/代理工具导出的 HAR（.har / .json）。请确保响应来自 App 的“全球购”商品列表，而非普通商品分类。

02 · 或粘贴响应 JSON

如果你已经复制了接口的 Response Body，可直接粘贴响应内容。只需要响应 JSON，不需要请求头或登录凭据。

03 · 识别结果

0件有效商品
0件包含图片
0未识别价格

图片商品名称分类 / 品牌价格商品ID

价格根据响应里的 priceInfo（优先 priceType=1）转换；如果接口没有返回现价，不会编造价格。导入前请在 App 里核对库存、规格和最终价。

如何使用

  1. 在山姆 App 正常进入“全球购”，打开你要整理的商品列表。
  2. 通过你已有的合法数据导出方式，保存该列表请求的 JSON 响应，或导出包含响应正文的 HAR。不要绕过登录、验证码或访问限制。
  3. 在本页面选择文件并解析，检查商品名称、价格和图片，再下载 CSV。
  4. 回到好物清单的组织者后台 → 商品管理 → 导入 CSV。重复导入前请先检查，当前版本不会自动合并重复商品。
实时同步的限制：山姆 App 目前没有向普通开发者公开的商品目录 API 文档。此工具做的是基于你已授权访问的 App 响应导入，不代表实时接口已经连通，也不会把价格自动持续刷新。若要定时同步，需先确认接口使用条件，并把访问凭据只保存在私有后端，而不是 GitHub 或公开网页。
